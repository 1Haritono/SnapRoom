# 3D & 2D Конструктор Корпусной Мебели (Furniture Designer)

Современное веб-приложение для проектирования корпусной мебели и виртуального планирования помещений.

## 🚀 История версий и Релизы

### 📌 Версия 1.1 (Текущий релиз)
- **Умная прозрачность стен в 3D**: Стены, находящиеся между камерой и мебелью, автоматически и плавно становятся прозрачными (`opacity ≈ 0.12`).
- **Интерактивное выделение объектов**: Клик по модулю подсвечивает его индиговым свечением в 3D и пунктирным контуром в 2D.
- **Инспектор свойств объекта (Floating Inspector)**: Плавающая панель с мгновенным реактивным изменением размеров (Ш×В×Г), положения (X,Y,Z), поворота и материалов.
- **Чёткие подписи стен**: Названия стен (А, Б, В, Г) с точными размерами в мм над каждой стеной на 2D-плане и в виде 3D Billboard меток.
- **Управление видом 2D**: Кнопки поворота плана на ±90° и сброса угла вида.

### 📌 Версия 1.0 (Базовый релиз)
- Создание проекта и настройка комнаты (Габариты или 4 стены A,B,C,D + поддержка ниш в стенах).
- Базовые модули корпусной мебели (Шкаф, Кухонный низ, Кухонный верх, Тумба).
- Назначение материалов (ЛДСП, МДФ, АГТ) отдельно для Корпуса и Фасадов с поддержкой загрузки текстур.
- 3D-сцена (Three.js/R3F) и 2D-план с сохраннением в LocalStorage.

## 🛠 Технологический стек
- **Framework**: Next.js 14 (App Router) + React 18 + TypeScript
- **3D Graphics**: Three.js + React Three Fiber (`@react-three/fiber`) + Drei (`@react-three/drei`)
- **Styling & UI**: Tailwind CSS + Lucide Icons
- **State**: Zustand (с плагином persistence)
