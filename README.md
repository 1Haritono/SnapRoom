# 3D & 2D Конструктор Корпусной Мебели (Furniture Designer)

Современный веб-инструмент для 3D/2D проектирования корпусной мебели и планирования помещений.

## 🚀 Возможности (Версия 1.0)
- **Планирование помещения**:
  - Параметры габаритов помещения (Длина × Ширина × Высота).
  - Режим задания 4 отдельных стен (А, Б, В, Г).
  - Добавление и проектирование ниш в стенах.
  - Поддержка фоновой подложки (загрузка плана или фото).
- **Корпусная мебель**:
  - Модули: Шкаф, Кухонный низ, Кухонный верх (с высотой от пола), Тумба.
  - Настройка ширины, высоты, глубины и угла поворота.
  - Интерактивное перетаскивание на 2D-плане.
- **Материалы и Текстуры**:
  - Выбор материала: ЛДСП, МДФ, АГТ.
  - Раздельное назначение материалов на **Корпус** и **Фасады**.
  - Загрузка кастомных картинок/текстур.
- **3D & 2D Визуализация**:
  - 3D-сцена на Three.js / React Three Fiber с освещением и тенями.
  - Переключение режимов 2D ↔ 3D.
  - Сохранение в LocalStorage.

## 🛠 Технологии
- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **3D Engine**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **State Management**: Zustand (с плагином `persist`)
